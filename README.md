# CarOMine

Finnish winter countryside car-building survival + retro FPS. You're an unemployed secret agent in Nurmijärvi - rebuild your old car, survive the cold, and shoot whoever shows up.

**By Crowelian 2026 + Sonnet.** Rust + Bevy. Target: macOS Apple Silicon first, then Windows/Linux.
