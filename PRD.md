# CarOMine - Product Requirements Document

By **Crowelian 2026 + Sonnet**. Machine-readable twin: `PRD.json` (task status lives there). Human task list: `task.md`.

## 1. Pitch
A Finnish winter-countryside survival/car-building sim in the spirit of *My Summer Car* / *My Winter Car* / *Mökkisimulaattori*, with a Build-engine (Duke3D / Shadow Warrior / Blood) style retro FPS layer: **you are an unemployed secret agent living in Nurmijärvi, Finland, in winter. Build your old car back from a pile of parts - and shoot the people who show up to stop you.**

## 2. Pillars
1. **Build the car** - simpler and more forgiving than MSC, but with *real* faults and real fixes (dead battery, fouled plugs, frozen fuel line, flat tyre, blown fuse...).
2. **Winter is the enemy** - slippery roads, snow on the windshield (Amiga *Toyota Celica GT Rally* style: flakes pile up unless you run the wipers), cold engines, short days, beautiful dark nights with good lights.
3. **Retro FPS** - 2D sprite enemies/trees/bushes/items as billboards, 3D cars + terrain, houses as 2D/3D hybrids. Fast hitscan guns.
4. **Finnish humour** - sauna, coffee, makkara, Kela benefits, moose, katsastus (inspection), K-market, mökki.
5. **Everything replaceable** - every asset (sprite, texture, model, sfx, music, car part, engine) is referenced through `assets/manifest.json` and documented in `assets.md`.

## 3. Platforms
- Primary: macOS, Apple Silicon (M1 Max), Metal via wgpu.
- Later: Windows (x86_64), Linux. Keep all code portable (no macOS-only APIs; paths via `std::path`; no inline asm).

## 4. Core gameplay loop
Wake in cabin -> eat/coffee/sauna (needs) -> do odd jobs / agency gigs for money -> buy/collect parts -> build/repair car in garage -> test drive on snowy roads -> fight enemies encountered -> pass katsastus -> final mission.

## 5. Features (see PRD.json for IDs)
| Area | Requirements |
|---|---|
| World | ~8x8 km heightmap terrain, flat/rolling Finnish countryside, spruce/pine/birch forests (billboards), fields, frozen lake, river, roads, Nurmijärvi village, home cabin, day/night, snowfall, aurora |
| Player | FPS controller, 5 weapons (fists, pistol, shotgun, SMG, hunting rifle), health/needs, interaction (E), inventory/tool wheel |
| Enemies | Billboard sprites, 8-angle, states idle/patrol/chase/attack/flee/dead. Ex-agency goons, rogue hunters, wolves, angry moose, drunk neighbour |
| Vehicle | Raycast vehicle, snow/ice/gravel/asphalt friction, tyre types, engine/drivetrain model, lights, wipers, windshield snow, crash damage |
| Building | Part DB (JSON), garage, install/remove/tighten, fault system, diagnosis hints, in-game manual, upgrades (winter tyres, studs, block heater...) |
| Life | Hunger, coffee, warmth, sleep, sauna; unemployment benefit + gigs; shops |
| Meta | Save/load, settings, EN+FI, credits |

## 6. Non-goals (v1)
Multiplayer, mod editor UI, full soft-body physics (Rigs of Rods) - we *import* RoR cars as simplified rigid placeholders only.

## 7. Technical requirements
- Rust (stable), Bevy engine (wgpu -> Metal/DX12/Vulkan). 60 FPS on M1 Max at 1080p.
- Data-driven: parts, enemies, weapons, items in JSON/RON under `assets/data/`.
- Billboards must be batched/instanced; forests of 50k+ sprites.
- Deterministic world from a seed.

## 8. Licensing & references (honest notes)
- References: Rigs of Rods (GPLv3), EDuke32 / NBlood / Shadow Warrior (GPL **source**). We take *design, formats and algorithms* as reference and write Rust code; any direct code port must stay GPL-compatible -> **CarOMine code is GPL-3.0-or-later**.
- **Game data of Duke3D / Shadow Warrior / Blood (sounds, art, music) is NOT free** (only the engine source is). We do **not** copy it. All shipped placeholders are generated by our own scripts (`tools/`), CC0-style. RoR content packs have per-mod licences; only import ones whose licence is checked and recorded in `assets.md`.

## 9. Definition of done (v1.0)
Player can build the starter car from parts, drive it on snowy roads with working wipers/snow-on-glass, get crash-damaged and repair it, fight at least 5 enemy types, survive needs, save/load, pass katsastus and finish the final mission, on macOS arm64 with a .app bundle.

## 10. Status (see task.md / PRD.json for the live list)
Playable vertical slice complete on Linux (verified by headless rendering); macOS Apple Silicon build is expected to work (same wgpu/Metal path) but **has not been run on a real Mac or GPU yet** - first thing to do on the target machine: `cargo run --release`, check frame rate, lighting (bloom/volumetrics were tuned in software rendering) and audio (no audio device existed in the dev sandbox).
Implemented: world (terrain, forest, farms, village, weather, day/night, aurora), FPS (5 weapons, 6 enemy types + boss, flashlight), car (physics, faults, workshop, dash, grime), life sim (needs, sauna, shops, gigs), story loop with ending, save/load, menus, EN/FI strings, console + cheats, Doom/ROTT-style pixel art rendered from 3D rigs.
Open: perf pass, gamepad + rebinding, RoR importer, inventory/tool wheel, mailbox/TV/interiors, quit-to-menu, remaining localisation, art polish passes.
