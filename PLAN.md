# CarOMine - Master Plan

Phases map 1:1 to `PRD.json`. Work **top-down**; always do the first non-done task in `task.md` unless it's blocked.

## Tech decisions (and why)
| Decision | Choice | Reason |
|---|---|---|
| Language | Rust | requested; safe, portable |
| Engine | **Bevy** (latest stable; pin in Cargo.toml) | ECS, wgpu->Metal on M1, easy custom billboard meshes, fast iteration |
| Physics | **Avian3d** or custom (decide in T-080) - terrain collision via heightfield, **custom raycast vehicle** | RoR soft-body is too heavy; raycast vehicle is stable and tunable for ice |
| FPS rendering | True 3D scene, **sprites as camera-facing quads** (Y-axis billboard) with 8-angle frame pick, unlit-ish w/ emissive for night | Build-engine look inside a 3D world with real cars |
| Data | JSON (serde) in `assets/data`, manifest in `assets/manifest.json` | AI/human editable |
| Assets | Generated by Python (`tools/gen_*.py`, Pillow+numpy+stdlib wave) | zero licensing issues, reproducible |
| Tasks | `PRD.json` source of truth, `tools/tasks.py` renders `task.md` | no drift |

## Phase summary
- **P1 Foundation** - compile a Bevy window w/ states + manifest-driven asset loader.
- **P2 Assets** - generate every placeholder first so code never waits on art.
- **P3 World** - terrain, billboards, forest, village, light, weather.
- **P4 Player+FPS** - controller, guns, enemies.
- **P5 Vehicle** - driving on snow, wipers/snow windshield, damage.
- **P6 Building** - parts, garage, faults, repair.
- **P7 Game loop** - needs, money, cabin, story, saves.
- **P8 UI/audio**, **P9 polish/release**.

## Game design cheat-sheet
- **Starter car**: "Volvo-ish" 240-style RWD wagon wreck (placeholder name *Saabo 99*). Delivered as boxes of parts at the garage.
- **Fault list (v1)**: dead battery, loose battery terminal, fouled spark plugs, clogged fuel filter, frozen fuel line (needs dry-gas), blown fuse, low coolant/leak, worn brake pads, flat tyre, loose belt, bad alternator, cracked windshield wipers (blades), stuck choke.
- **Crash damage**: per-part HP; body panels swap between 3 mesh states (ok / dented / crumpled); engine/suspension damage changes handling; fix = buy part or quick "hammer+weld" mini-interaction.
- **Winter grip**: surface friction table x tyre type multiplier (summer 0.45 on snow, winter 0.8, studded 1.0, ice halves each; asphalt dry ok).
- **Windshield snow**: shader/overlay with a coverage float 0..1 growing with snowfall*speed-dependent; wipers (2 speeds) clear a sweep arc; defrost handles frost; washer fluid resource.
- **Enemies**: ex-agency goons (hitscan pistol), rogue hunters (rifle), wolves (melee, fast), moose (charge, car hazard), drunk neighbour (comic melee).

## Quality rules
1. Every task ends with: `python3 tools/tasks.py done T-xxx "note"` + commit to `main` + push.
2. Keep `CONTINUE.md` "STATE" section current (what is half-done, exact next command).
3. Never hardcode asset paths; go through the manifest.
4. `cargo check` must pass before commit once P1 exists.
